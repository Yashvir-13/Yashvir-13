# Yashvir
**Logic • Behavior • Aesthetics**

*"Still trying to understand what I'm looking at."*

---

<div align="left">
I’m interested in the points where logic, behavior, and aesthetics collide. Most of my work involves building systems that try to handle the "messiness" of the world—whether that's the unpredictability of a global crisis, the nuances of a sign language gesture, or the emergent deception in a multi-agent system.
<br /><br />
I don't think AI should be a black box. I'm more interested in it as a tool for clarity: a way to study how agents cooperate, how we communicate, and how we can protect the logic of a creative frame.
</div>
